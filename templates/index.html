Known Limitations

Digital Shadow is a heuristic tool, not a formal security audit.

⚠ Analysis is limited to information you voluntarily submit. It does not search the internet or access external data sources.
⚠ Phone number and physical address detection may produce false positives depending on the text format.
⚠ URL analysis is structural only — no outbound network requests are made to any URL you submit.
⚠ The risk score is a heuristic estimate. It is not a formal cybersecurity audit or legal privacy assessment.
⚠ Document metadata extraction depends on the file format and available parsing libraries.
